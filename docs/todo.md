## 進め方と完成目標

[企画書・開発引き継ぎ書](handoff.md)に基づく、ユーザー本人が実装を進めるためのチェックリスト。主な開発・実行環境は、Intel x64の物理Windows 11 PCとする。macOSはソース編集と、シミュレーション・AIの移植性確認に使用する。

ゲーム部分の完成目標は、固定の斜め見下ろし視点で、球体をWASDで操作し、往復する障害物を避けてゴールへ進める1ステージである。シミュレーションは描画から独立させる。

2026年11月16日の提出には、遺伝的アルゴリズムによるプレイの改善、学習結果の保存、保存済みAIの画面上での再実行も必要。ステージクリアは必須としない。

各節の完了条件を確認してから次へ進む。チェック項目は実施予定であり、動作確認済みの記録ではない。

手順2以降のC++実装は、[サンプルコード付きの入門教材](cpp_tutorial.md)を参照する。コードの配置先、処理の理由、ビルド・検証方法を順に説明している。

## 1. Windows PCにプロジェクトをcloneする

- [ ] Windows PCにGitをインストールし、PowerShellで`git --version`を確認する。
- [ ] GitHubへのアクセスを確認する。非公開リポジトリの場合は、アクセス権のあるアカウントで認証する。
- [ ] ソースコードを置く親フォルダーを作り、その場所で以下を実行する。

  ```powershell
  git clone https://github.com/JUPIPIYO/sphere_is_learning.git
  cd sphere_is_learning
  git remote -v
  git status
  ```

- [ ] `AGENTS.md`と`docs/handoff.md`を読む。
- [ ] 必要な文書がWindows側にもあることを確認する。別PCの未コミット・未pushの変更はcloneに含まれないため、必要ならそのPCで内容を確認してGitHubへ反映し、Windows側で取得する。
- [ ] コミット用のユーザー名・メールアドレスを確認する。
- [ ] 作業用ブランチを作成する。

**完了条件：** Windows側でリポジトリと最新の開発方針を確認できる。

## 2. C++20とCMakeのビルド環境を作る

- [ ] Visual StudioまたはBuild Toolsに、C++の開発ツール、MSVC、Windows SDK、CMakeを用意する。
- [ ] C++20・x64構成で、最小のC++プログラムをビルドできることを確認する。
- [ ] `CMakeLists.txt`を作成し、次の対象を分ける。
  - シミュレーション用ライブラリ：`src/core`
  - Windows描画アプリ：`src/app`、`src/renderer/d3d11`
  - ヘッドレス実行アプリ
  - 自動テスト：`tests`
- [ ] Windows描画アプリとDirectX関連の依存関係は、Windowsでのみビルドするようにする。
- [ ] シミュレーション側からWindows・DirectX・ImGuiのヘッダーを参照しない構成にする。
- [ ] ビルド・テスト用の最小構成を用意し、CTestでテストを実行できるようにする。
- [ ] ビルド生成物を`.gitignore`に追加する。
- [ ] 実際に使用した構成・ビルド・テストのコマンドを`README.md`に記録する。

**完了条件：** Windowsで空のアプリと最小テストをビルド・実行できる。

**早期確認：** この段階で手順6の「背景色の表示」まで一度試し、Windows SDKとDirect3D 11の初期化に問題がないか確認する。その後はシミュレーションの実装へ戻る。
